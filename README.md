# 局域网私人德州扑克

这是一个在本机运行的私人德州扑克网页游戏，支持 2–9 个座位、邀请朋友加入、实时聊天、下注、全下、边池结算，以及人数不足时添加三种风格的 AI 玩家。

> 本项目仅供娱乐。所有筹码均为虚拟筹码，不能购买、提现、兑换，也不代表任何真实货币或财物。

## 环境要求

- 推荐 Node.js 24（至少使用支持本项目依赖的现代 Node.js 版本）
- 启动机器和朋友的设备需要连接到同一个彼此可达的局域网
- 项目不会自动修改系统防火墙，也不会把服务发布到公网

## 开发模式启动

```bash
cd /home/sxy/lan-texas-holdem
npm install
npm run dev
```

开发模式会同时启动两个进程：

- Vite 前端监听 `0.0.0.0:5173`；浏览器应打开 Vite 输出的 `http://局域网IP:5173`
- Socket.IO/Express 服务监听 `0.0.0.0:3000`；Vite 会把 `/socket.io` 代理到此端口

本机通常可打开 `http://localhost:5173`。朋友应使用 Vite 在终端打印的 Network 地址，而不是 `localhost`。

## 生产模式启动（推荐局域网一起玩）

生产模式先构建前端，再由一个服务在 3000 端口同时提供网页和实时牌局：

```bash
cd /home/sxy/lan-texas-holdem
npm install
npm test
npm run build
npm start
```

启动成功后终端会显示类似地址：

```text
本机：http://localhost:3000
局域网：http://192.168.1.24:3000
```

在启动机器上使用 `localhost` 即可。朋友需要在同一可达局域网中打开终端实际打印的 `http://局域网IP:3000` 地址。可使用 `PORT=4173 npm start` 改端口，端口必须是 1–65535 的整数；可使用 `HOST=192.168.1.24 npm start` 指定监听地址，默认监听 `0.0.0.0`。

停止服务时在终端按 `Ctrl+C`。进程会关闭行动/断线计时器、Socket.IO 连接和 HTTP 服务。

## 创建房间并邀请朋友

1. 打开首页，输入昵称并创建房间。
2. 在房间里复制邀请链接，通过局域网聊天工具发给朋友。邀请链接只包含房间号，不包含你的会话令牌。
3. 朋友打开链接、输入自己的昵称并加入。
4. 人数不足时，房主可以添加“保守型”“均衡型”或“激进型”AI；单桌真人与 AI 合计最多 9 个座位。
5. 房主可调整初始筹码和大小盲，至少两名有筹码的玩家就座后即可开始。
6. 轮到自己时可根据服务端给出的合法操作选择弃牌、过牌、跟注、下注、加注或全下；加注输入表示“加注到”的总额。
7. 右侧聊天区可发送普通文字。行动限时为 30 秒，超时会自动过牌（可过牌时），否则自动弃牌。

刷新页面后，浏览器会尝试使用本机保存的会话令牌恢复座位。同一个会话在新标签页或新连接恢复后，旧页面会显示已被替换，避免一个身份同时操作两次。

## 局域网访问范围与常见问题

- 手机使用移动数据、朋友连接其他 Wi-Fi，或设备不在同一个可达局域网时，通常无法访问此地址。这是当前“仅局域网”方案的预期行为。
- 公司/访客 Wi-Fi 可能启用客户端隔离，使同一 Wi-Fi 下的设备也无法互访；企业防火墙也可能阻止 3000 或 5173 端口。需要由网络管理员放行相应端口或关闭隔离，本项目不会自行更改这些设置。
- 若终端打印多个局域网地址，请选择和朋友设备处于同一网段的地址，例如双方都是 `192.168.1.x`。
- 若页面能打开但牌局无法实时更新，确认开发模式的 3000 端口也未被防火墙阻止，并检查两个启动进程是否都仍在运行。
- 不建议把本服务直接映射到公网；它按可信私人局域网娱乐环境设计。

## 数据与隐私说明

- 房间、玩家会话、聊天记录、牌局和虚拟筹码全部只保存在服务器内存中。
- 重启或停止服务会清空所有房间和牌局，无法恢复。
- 每个房间只保留最近 100 条聊天消息。
- 服务器是发牌、合法操作、AI、计时和结算的唯一权威来源；客户端不会收到其他玩家未摊牌的底牌、剩余牌堆或他人的会话令牌。

## 验收说明

自动化测试覆盖双客户端创建/加入、聊天、开局、行动、超时、AI、隐私投影、断线重连、健康检查和生产静态页面。当前开发环境没有可控制的第二台实体手机，因此“手机与电脑处于同一局域网”的现场连通性，以及企业 Wi-Fi 是否存在客户端隔离，仍需在实际网络中按上面的生产模式步骤验证；本项目没有伪造该项结果，也没有修改系统防火墙。
